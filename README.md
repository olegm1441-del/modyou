# MODYOU

Адаптивный сайт MODYOU на React 19 + Vite 8. Подготовлен к запуску на Railway через Dockerfile.

## Локальный запуск

Требуется Node.js 24 LTS.

```bash
npm ci && npm run build && npm start
```

Открыть http://localhost:3000. Для разработки: `npm run dev`.
Проверка типов: `npm run typecheck`.

## Railway

1. Подключить этот GitHub-репозиторий к сервису Railway, ветка `main`, корневая директория `/`.
2. Использовать Dockerfile из корня. Отдельные build/start commands не нужны.
3. Healthcheck path: `/healthz`, timeout: 60 секунд.
4. Generate Domain; приложение слушает `0.0.0.0:$PORT` (локально 3000).
5. Обновления ветки main разворачиваются автоматически после подключения репозитория.

Контейнер запускает только Node.js и собранные файлы сайта, от пользователя node.
Для текущей демонстрационной версии база данных, том и секреты не требуются.

## Что работает

- Главная, два формата STANDART/PRO, демонстрационный конструктор, коллекция и фильтры.
- Избранное, образ и корзина сохраняются локально в браузере.
- Демонстрационный путь оформления заказа и статусы.
- Мобильное меню, адаптивные сетки, клавиатурная навигация и страница 404.
- Прямые URL внутренних страниц обслуживаются сервером.

## Границы версии

Исходный архив содержит демонстрационный прототип. Настоящие платежи, авторизация,
серверная база заказов, логистика и мобильное приложение не подключены.
Цены, условия, контакты, фотографии команды, отзывы и юридические тексты требуют
утверждённого контента. Выбор большинства параметров конструктора пока сохраняет
описание, но не меняет геометрию изображения. Не вводите реальные платёжные данные.

`/editor` — локальный редактор: изменения видны только в браузере пользователя.
Это не общая административная панель. Данные сайта редактируются в `data/content.ts`.
